# «Мужчины в трико» — Hiatus Chart

Интерактивный недельный календарь выпусков и пауз подкаста «Мужчины в трико» по данным официального RSS-фида Mave.

## Обновление данных

```sh
npm run sync
```

Для повторяемой сборки можно передать локально сохранённый RSS:

```sh
MAVE_RSS_FILE=/path/to/feed.xml npm run sync
```

## Сборка и запуск

```sh
npm run build
npm run dev
```

Календарь будет доступен на <http://localhost:4173>.
